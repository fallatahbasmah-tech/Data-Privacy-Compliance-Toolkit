# 🔐 Data Privacy – A Compliance Toolkit

### 🎓 Cybersecurity Graduation Project
**Taibah University | Applied College | Cybersecurity Department**

## 📌 Project Overview

Data Privacy – A Compliance Toolkit is a cybersecurity graduation project designed to help organizations evaluate their compliance with the General Data Protection Regulation (GDPR).

The project focuses on data privacy, regulatory compliance, risk assessment, and data protection awareness.

It provides a web-based GDPR self-assessment tool that allows organizations to answer compliance-related questions and review their assessment results.

## 🎯 Project Objectives

- Support organizations in evaluating GDPR compliance.
- Identify potential data privacy risks.
- Provide recommendations for improving data protection practices.
- Increase awareness of GDPR requirements.
- Simplify the compliance self-assessment process.

## 🔍 Key Features

The project is designed around the following capabilities:

- **GDPR Self-Assessment:** Structured questionnaires covering data protection requirements.
- **Compliance Evaluation:** Assessment of organizational responses.
- **Risk Analysis:** Identification of potential compliance risks.
- **Recommendations:** Guidance for improving data protection practices.
- **Reporting:** Presentation of compliance assessment results.
- **User-Friendly Interface:** Web-based interaction with assessment questions and results.

## 🏗️ System Architecture

The system follows a three-tier architecture:

1. **Presentation Layer:** HTML, CSS, and JavaScript.
2. **Application Layer:** Python and Flask.
3. **Database Layer:** MySQL.
